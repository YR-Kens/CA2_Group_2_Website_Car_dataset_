Car Data

Project Made by Yaseen Rahman, Zehad

For this project we selected an available dataset from Kaggle.com

Our objective was to analyse the dataset, create a machine learning linear regression graph, and display our work in this website

Car Body Types

in this chart we can see visually that SUV dominates this dataset, followed by sedan and hatchback. This particular stat can mean that the target marked of the cars of this dataset was for families.

Transmission Types Distribution

we can see a very high dominance of automatic cars. Which fits the target of families, because automatic makes driving easier and relatively safer.

Fuel Types Distribution

One type is dominating the chart (petrol), meaning, dataset is displaying cars with a cheaper maintanance.

But the presence of the scatter points, alters the slope of the line. The scatter points can be explained by saying that there are expectations, for example an old car might have hight torque but since of the year its starting price won't relate to the graph.
